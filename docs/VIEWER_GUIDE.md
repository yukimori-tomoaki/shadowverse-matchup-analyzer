# Shadowverse Matchup Analyzer 閲覧者向け取扱説明書

## 1. このページについて

このページは、共有されたShadowverse対戦データから作成されたデッキ別相性表です。

閲覧にログインは必要ありません。

```text
閲覧URLの例
https://<公開ドメイン>/share
```

## 2. 開き方

1. 管理者から受け取った`/share` URLを開く
2. 「閲覧専用」と表示されることを確認する
3. 相性表の読み込みが完了するまで待つ

`localhost:3000` で始まるURLは管理者PC専用です。インターネット上で閲覧する場合は、Vercelなどの公開ドメインから始まるURLを使用してください。

## 3. 相性表の見方

- 縦軸：自分デッキ
- 横軸：相手デッキ
- セルの大きな数字：勝率
- セルの中央の数字：勝利数 - 敗北数
- セル下部：総対戦数と相性評価
- 対角線：同じデッキのため`—`
- 対戦なし：`N/A`

勝率の色分け：

- 60%以上：大幅有利
- 55.0〜59.9%：有利
- 45.0〜54.9%：五分
- 40.0〜44.9%：不利
- 39.9%以下：大幅不利

5戦未満の組み合わせは、データ不足として強い色を付けません。

## 4. 詳細表示

相性表のセルをクリックすると、詳細パネルが開きます。

表示内容：

- 自分デッキ
- 相手デッキ
- 勝率
- 勝敗数
- 総対戦数
- 先攻勝率
- 後攻勝率

詳細パネルを閉じるには、右上の閉じるボタンまたは背景部分をクリックします。

## 5. リアルタイム更新

管理者が同じ公開URLに対戦データを追加すると、相性表は自動更新されます。

反映されない場合は次を試してください。

1. ブラウザを再読み込み
2. 数秒待つ
3. URLが途中で切れていないか確認
4. 管理者が別の公開URLを発行していないか確認

## 6. 閲覧できない場合

### localhostで接続拒否される

URLが次のようになっている場合、管理者のPCが起動している時だけ閲覧できます。

```text
http://localhost:3000/...
```

管理者へVercelなどの公開ドメインの`/share` URLを依頼してください。

### 公開ページを表示できません

公開URLが無効化された、URLが間違っている、またはSupabase側の公開設定が未完了の可能性があります。

管理者へURLの再発行を依頼してください。

### 相性表が空のまま

- ネットワーク接続を確認
- ページを再読み込み
- 管理者がCSVを読み込み済みか確認
- URLが`/share`で終わっているか確認

## 7. 閲覧者ができないこと

公開ページは閲覧専用です。

- CSVの追加
- 対戦データの削除
- 公開URLの変更
- 相性表の編集

これらは公開元の管理者が行います。

## 8. データの扱い

公開URLを知っている人は、そのURLに紐づく相性表を閲覧できます。URLを第三者へ転送しないでください。

相性表の内容に誤りがある場合は、公開元の管理者へ連絡してください。
